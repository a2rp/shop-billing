# Shop Billing

A lightweight vanilla JavaScript billing app for small shops. Create itemized bills, apply discounts, save drafts and bill history in the browser, and print a clean receipt.

## Features

- Item rows with price, quantity, and percentage or amount discounts
- Bill-level discount and grand total calculation
- LocalStorage draft saving and saved bill history
- Search, reopen, delete, and print saved bills
- Responsive fixed-header layout with store settings, print-ready slips, and a floating scroll-to-top control

## Tech stack

- HTML, CSS, Sass, and vanilla JavaScript
- LocalStorage for browser-only data

## Run locally

Open `index.html` in a browser or use a local server such as VS Code Live Server.

To edit Sass, compile it with:

```bash
sass --watch style.scss:style.css
```
